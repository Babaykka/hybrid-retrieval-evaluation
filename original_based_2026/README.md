# Редакторская версия статьи

В [source](source/) сохранена последняя редакторская версия статьи на русском и английском языках: PDF, исходники LaTeX и необходимые рисунки. Команды сборки приведены в [source/README.md](source/README.md).

Эта версия сохраняет прежние численные значения и соответствующие выводы. Её нельзя смешивать со [статьёй с пересчитанными результатами](../delivery_revision/README_RU.md). Код и результаты пересчёта находятся в [revision_2026](../revision_2026/).

[ПОЯСНЕНИЕ.md](ПОЯСНЕНИЕ.md) описывает границы редакторских изменений и расхождения между версиями. Наличие обеих версий отражает различие между редакцией текста и пересчётом экспериментов.
