# Project Vault

Личный навык Codex для сохранения законченных проектов: обезличенная разработка
и результаты в GitHub, полный разрешенный комплект и описание в Telegram,
проверка восстановления и освобождение локального места.

Скопируйте эту папку в `~/.codex/skills/project-vault` или в
`$CODEX_HOME/skills/project-vault`, затем откройте новый чат Codex. Пример запроса:

> Используй $project-vault: сохрани законченный проект из текущей папки,
> подготовь публикацию и проверь восстановление.

Навык содержит инструкции и два помощника. `scripts/inventory.py` составляет
инвентаризацию; `scripts/catalog.py` ведет отдельный зашифрованный каталог для
личного поиска. Помощники сами не выполняют обезличивание и публикацию.

Для каталога нужен Python с `cryptography`. Порядок работы и защиты ключа описан
в [references/catalog-lookup.md](references/catalog-lookup.md). Настройки
хранилищ находятся в [SKILL.md](SKILL.md); перед применением к новым заказам
проверьте выбранный канал и фактическую авторизацию публикации.

Личные записи, ключи, внутренние отчеты и учетные данные в этот пакет не входят.
