# Редакция статьи DAMDID 2026

Заявка 90. Редакция от 14 сентября 2026 года.

## Основные файлы

- `manuscript_en.pdf` и `manuscript_en.tex`: английская версия для подачи и её редактируемый исходник.
- `manuscript_ru.pdf` и `manuscript_ru.tex`: согласованная русская версия для работы с текстом.
- `reviewer_responses_en.tex` и `reviewer_responses_ru.tex`: ответы рецензентам, уже включённые в конец соответствующего PDF.
- `references.tex`: общий список литературы.
- `tables/`, `results_macros.tex`, `fullset_interpretation_*.tex`: таблицы и численные результаты.
- `figures/`: все рисунки в PDF, PNG и редактируемом SVG.
- `reproducibility/`: исходники расчётов и построения рисунков, численные результаты и сведения о проверках.
- `AUTHOR_NOTES_RU.md`: существенные изменения результатов и оставшееся уточнение по источникам кандидатов.

Для передачи редактируемой статьи нужен весь комплект исходников, а не только главный `.tex`: он подключает таблицы, рисунки и библиографию из соседних файлов. Архив `DAMDID_90_revision_2026-09-14.zip` содержит полный комплект.

## Компиляция

Используется стандартный класс Springer LNCS без изменения размеров страницы или основного шрифта. Нужен XeLaTeX из TeX Live/MacTeX, пакет шрифтов Computer Modern Unicode (`cm-unicode`), `fontspec`, `polyglossia`, `microtype`, `graphicx`, `booktabs`, `tabularx`, `amsmath`, `amssymb` и `hyperref`.

Из каталога с исходниками:

```sh
latexmk -xelatex -interaction=nonstopmode -halt-on-error manuscript_en.tex
latexmk -xelatex -interaction=nonstopmode -halt-on-error manuscript_ru.tex
```

При отсутствии `latexmk` достаточно выполнить `xelatex` для каждого главного файла дважды. Библиография уже находится в `references.tex`; отдельный запуск BibTeX не требуется. Для сборки статьи не нужны Python, модели, интернет или архив исходных данных.
